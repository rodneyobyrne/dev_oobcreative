# oobCREATIVE Visual Direction

## Core principle

oobCREATIVE provides a clean, calm, structured visual container. The target persona and the content determine the emotional atmosphere inside that container.

> Minimal brand. Emotionally specific content.

The brand must remain recognizable across audiences without imitating every audience's emotional state.

## Brand feeling

The oobCREATIVE brand should feel:

- Clean
- Familiar
- Confident
- Structured
- Refreshing
- New
- Human without becoming sentimental
- Creative without becoming chaotic

## Default visual mode

The default website experience is:

- High contrast
- Predominantly black, white, and restrained neutral gray
- Spacious and uncluttered
- Primarily typographic
- Organized with clear section rhythm
- Supported by sparse hand-drawn marks
- Free of unnecessary decoration

Photography is not the default visual system.

## Visual hierarchy

Use this order of importance:

1. Typography
2. Space
3. Structure
4. Hand-drawn line accents
5. Photography only when emotionally justified

## Typography

Use a clean sans-serif system with generous scale and spacing.

The visual character of the `oobCREATIVE` word treatment may inform headings through:

- Tone-on-tone color shifts
- Contrasting font weights
- Selective emphasis within a phrase
- Strong black-and-gray relationships

Do not turn every heading into a stylized wordmark. Use the treatment selectively.

## Layout

Use:

- Generous page margins
- Wide breathing room between sections
- Strong alignment
- Mostly one- and two-column layouts
- Short, readable line lengths
- Few primary choices at one time
- Large visual pauses
- Simple horizontal section divisions

Avoid:

- Dense card grids
- Dashboard-like interfaces
- Repeated boxed panels
- Decorative clutter
- Large numbers of visual elements competing at once

## Hand-drawn visual language

The hand-drawn quality of the logo may be echoed through restrained supporting marks:

- Irregular horizontal rules
- Partial frames
- Underlines
- Corner marks
- Small arrows
- Sparse doodles
- Simple visual connectors

These marks should feel intentional and human, not playful or childish.

Do not use repeated open-box illustrations as decorative icons. The box drawing belongs to the protected logo lockup.

## Motion

Motion should remain restrained and useful:

- A line drawing into place
- A partial frame completing
- A subtle tonal shift
- Controlled content reveal
- Small hover movement on arrows or underlines

Avoid parallax, floating objects, glowing interfaces, and decorative animation.

## Persona modulation

The persona may influence:

- Copy tone
- Page pacing
- Information density
- Image subject
- Image crop
- Light and shadow
- Proof presentation
- CTA wording
- Visual tension

The persona must not alter:

- The logo
- Core typography
- Base color system
- Navigation behavior
- Button system
- Overall grid logic
- Fundamental brand identity

## Implementation rule

When a design decision is uncertain, choose the cleaner and simpler option unless the content requires additional emotional texture.
