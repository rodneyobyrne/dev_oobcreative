# Decision: oobCREATIVE Visual Direction

## Decision

oobCREATIVE will use a minimal, high-contrast, spacious visual system led by typography, structure, and restrained hand-drawn line accents.

Photography is a persona- and content-driven exception rather than the default. When used, it will favor close-up actions, working materials, and process details instead of faces, full-body figures, or generic lifestyle scenes.

The word treatment and open-box illustration are one protected logo lockup. The box will not be separated, redrawn, repaired, or reused as a decorative icon.

## Reason

The brand should remain clean, confident, familiar, structured, refreshing, and new. Emotional variation belongs primarily to the content and persona treatment rather than to multiple competing visual identities.

## Affects

- Homepage design
- Header and footer
- Typography
- Image selection
- Doodle and line usage
- Persona-specific page presentation
- Component styling
- Asset handling

## Supersedes

Any concept that:

- Uses altered or substitute box illustrations
- Treats the logo box as a repeated standalone icon
- Relies on image-heavy layouts
- Uses photographs by default
- Uses generic people imagery, silhouettes, or happy-face stock photography
