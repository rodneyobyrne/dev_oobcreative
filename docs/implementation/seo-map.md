# SEO Map

## Core rule

Use descriptive service language in page titles, H1 headings, URLs, navigation, internal links, introductory copy, and case-study links.

Use emotional or branded language as secondary headings and recognition pathways.

## Persona rule

Do not use internal persona names in URLs, page titles, metadata, or public navigation.

## Development indexing

Development and temporary Bluehost environments should not be indexed until the production domain and launch readiness are confirmed.

## Open decisions

- Production domain and canonical URLs
- Regional versus broader search positioning
- Service pages included at launch
- Start Here page and URL
- How We Work page and URL
- Structured data appropriate to actual content
