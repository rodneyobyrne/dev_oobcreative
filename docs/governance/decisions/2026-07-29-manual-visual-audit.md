# Manual Visual Audit Decisions

## Approved decisions

1. `Mark.svg` is the primary website logo.
2. The global navigation is black and uses the mark only.
3. Full `Mark + oobCREATIVE` lockups are reserved for formal locations.
4. The footer uses `public/branding/logo_horiz#111111_background.png`.
5. The footer browser URL encodes the filename as `/branding/logo_horiz%23111111_background.png`.
6. Horizontal rules and vertical layout separators use the layered rough-brush style represented by Example 3 in the supplied line-animation reference.
7. Buttons, CTA boxes, and other formal action boundaries remain geometric.
8. The optional text wordmark uses regular gray `oob` and bold white `CREATIVE` on dark backgrounds.

## Supersedes

Any prior guidance that places a full lockup in the global header or uses a normal straight CSS border for primary section and content separators.
