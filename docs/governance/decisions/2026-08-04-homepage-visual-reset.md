# Decision: Homepage Visual Reset

**Date:** 2026-08-04  
**Status:** Approved working direction

## Decision

Reset the homepage implementation around a simpler, less content-dense structure.

## Preserve

- approved black navigation
- mark-only header identity
- existing navigation scale and CTA treatment

## Implement

- sticky header behavior
- approved H1–H4 type hierarchy
- slightly larger low-end supporting type
- rough hand-drawn horizontal and vertical structural rules
- three-path layout
- three selected-work items
- one direct CTA
- formal footer lockup
- sparse secondary brand elements

## Reject

- dense card systems
- excessive explanatory content
- repeated image grids
- AI-perfect geometric separators
- full lockup in the header
- black-box mark treatment on white
- decorative logo approximations
