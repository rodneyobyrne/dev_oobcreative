# Decision: Link and Hover Motion

**Date:** 2026-08-04  
**Status:** Approved interaction behavior

## Navigation Links

Navigation links use a left-to-right underline animation.

The underline:

- uses the current text color
- begins at the left edge
- remains visible for the active page
- does not alter the approved navigation layout

## Text Links

Text links use the same left-to-right underline motion.

Arrow glyphs move slightly to the right on hover and keyboard focus.

## Buttons

Buttons remain geometric and use strong inverse hover states.

- outline button: black background, white text
- primary black button: white background, black text
- navigation CTA: white background, black text

Hover states must remain readable and meet contrast expectations.

## Accessibility

- keyboard focus remains visible
- visited links retain the intended color
- reduced-motion preferences disable transitions
