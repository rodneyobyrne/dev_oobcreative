# Asset Register

## Brand assets

|---|---|---|---|---|
| oobCREATIVE logo lockup, PNG | `/public/brand/oobcreative-logo.png` | Approved | Website header, footer, documents, approved brand applications | Do not separate, redraw, crop, distort, recolor, or reuse the box independently |

## Image assets

Add photography only after confirming:

- The persona or content benefits from additional human or lifestyle texture
- The image shows close-up action rather than a generic person
- Publication and usage rights are documented
- Alt text is defined
- The image does not duplicate another image already used nearby

## Asset intake fields

Record the following for every new visual asset:

- File name
- Repository path
- Source or creator
- Usage rights
- Date added
- Approved pages
- Alt text
- Crop notes
- Status: working, approved, published, or deprecated
