# Logo Usage

## Approved asset

Primary raster asset:

```text
/public/brand/oobcreative-logo.png
```

Add an approved SVG version later when available:

```text
/public/brand/oobcreative-logo.svg
```

Use SVG on the website when a verified vector file exists. Until then, use the PNG without alteration.

## Lockup rule

The `oob` word treatment and open-box illustration form one complete logo lockup.

Do not:

- Separate the word treatment from the box illustration
- Redraw the box
- Simplify the box
- Repair or regularize the hand-drawn lines
- Reinterpret the box as a generic open-box icon
- Use the box as a standalone decorative symbol
- Recreate the logo with live text
- Add shadows, effects, outlines, or colors
- Place the logo inside another hand-drawn frame

## Presentation

- Preserve the original proportions.
- Maintain generous clear space.
- Use only on backgrounds with sufficient contrast.
- Do not crop the lockup.
- Do not stretch or distort the image.
- Do not use low-resolution copies when a larger original is available.

## Supporting marks

The website may echo the hand-drawn line quality through rules, underlines, arrows, and partial frames. Those marks must remain clearly secondary and must not resemble alternate versions of the logo.
